# Demo hat photos

AI-generated stand-ins (OpenRouter, google/gemini-3.1-flash-image) for the seed catalog,
so the store looks like a hat brand before real photography exists.
Product shots are square on pure white, three angles per colourway
(`-1` three-quarter front, `-2` back or side, `-3` side or top-down; the black
Everyday Cap adds `-4` top, `-5` underside, `-6` buckle). Each extra angle was
generated from the colourway's `-1` shot as a reference so it shows the same hat. They show no
brand marks. Replace them with real product photos by uploading images to each
product in the Medusa admin; the seed only points at these files.
